# Local Model Manager 0.6.0

Первый установочный выпуск для Windows 11 x64.

- Подключение локального GGUF к LM Studio через символическую ссылку.
- Оценка памяти и подбор GPU offload для контекста Hermes 65 536 токенов.
- Загрузка модели с проверками ресурсов и фактического состояния.
- Проверка OpenAI-совместимого API и экспорт профилей Hermes для этого ПК и LAN.
- Автоматическая проверка стабильных GitHub Releases при запуске и каждые 6 часов.
- Фоновая загрузка и проверка пакета; установка по кнопке «Обновить и перезапустить».
- Панель обновления остаётся видимой вне прокрутки.

## Установка

Скачайте `LocalModelManager-win-x64-Setup.exe` из Assets и запустите один раз.
.NET включён в установщик. Для работы с моделями отдельно нужны LM Studio и драйвер NVIDIA.

Выпуск не подписан сертификатом Authenticode; Windows может показать предупреждение издателя.
Приложение не копирует GGUF автоматически и не меняет текущий профиль Hermes.
