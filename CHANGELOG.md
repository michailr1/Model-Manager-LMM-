# История изменений

## 0.6.0

- Первый установочный выпуск Windows x64 с включённым .NET 8.
- Автообновление из стабильных GitHub Releases: проверка и скачивание в фоне, перезапуск по кнопке в состоянии простоя.
- Панель обновления закреплена вне прокрутки; настройки сохраняются отдельно от программы.
- GitHub Actions: сборка, тесты и публикация выпуска при повышении версии.
- Включены существующие этапы M1–M5: GGUF, ссылки LM Studio, оценка памяти 64K, загрузка и проверка API для Hermes.
