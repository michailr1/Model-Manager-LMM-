# Внесение изменений

Windows 11 x64, .NET 8 SDK, C# и WPF. Перед изменением прочитайте [AGENTS.md](AGENTS.md).

1. Сначала определите конкретный этап и критерии проверки.
2. Внесите минимальное изменение без несвязанного рефакторинга.
3. Выполните `dotnet build -c Release` и `dotnet test -c Release`.
4. Изменения в интеграции дополнительно проверьте на настоящем LM Studio; поддельный CLI в тестах не подтверждает runtime.
5. Обновите документацию и описание изменений. Порядок выпуска — [docs/UPDATES.md](docs/UPDATES.md).

Не добавляйте GGUF, личные профили Hermes, API-ключи, `.env`, логи с секретами и результаты сборки. В issue указывайте версию приложения, Windows/LM Studio, ожидаемое и фактическое поведение; удаляйте токены и личные данные из логов.
